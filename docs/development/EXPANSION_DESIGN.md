# 从影视证据到互动世界

## 单一事实来源

源媒体内容摘要标识原片，素材路径只是可重定位的位置。原片不被代理、裁剪或模型输出替换。每个派生产物保留来源、秒区间、处理配方和模型信息；不同编码导致的时间精度差异应在导出说明中保留。

实体跨素材与剧集存在；标注锚定具体媒体区间/区域。模板定义可编辑字段的类型，实例字段不能绕过枚举、必填或数值校验。观察、解释、虚构为明确枚举，不用置信度替代证据身份。

事件把实体参与者、原片证据与状态变化连接起来；关系是带证据的有向边。故事时间用于叙事排序，不覆盖播放器定位时间。角色知识、资源、信任、持有物等可以作为类型化状态表示。

## 从原剧情到可玩分支

故事记录由节点、变量与选择组成。选择包含前置条件与原子效果，状态先完整验证再提交。变量类型不能隐式转换，条件与效果不执行任意用户代码。玩家会话是临时副本，不回写原片事件或角色资产。

原片证据跳转使用媒体 ID 与范围，故事分支引用事件 ID。新库导入时同时映射所有语义引用；节点/选择 ID 保留故事内作用域。故事图可以循环，编辑器应报告潜在循环、不可达节点和非结局死路，试玩有步数限制。结构可达性不等价于所有条件组合可达，需要状态测试。

## 工作台分工

- 素材库：检索与候选，包含剧集上下文、媒体状态及首次参考定位。
- 资产：跨素材人物、场景、道具、声音与属性，列表与参考关联。
- 标注：播放器、时间轨、空间绘制、模板字段、审核和证据身份。
- 工具：分析建议、参考生成、代理、源校验、模型状态与本地设置。
- 故事：事件、关系、状态变化、节点/选择编辑、预演与外部导出。
- 集合：为具体创作任务选成员和导出格式；裁剪配置不改变原标注。

## 失败与恢复

SQLite 迁移保留旧项目；写操作事务化并串行化。失败批次不部分接受标注。持久化的有界历史支持撤销/重做；恢复备份替换完整图，恢复前图保留为一次可撤销操作。媒体文件不因元数据撤销或删除而移除。

备份复制并校验实际字节，不把损坏或丢失原片当作成功备份。导入先检查路径、大小、摘要、schema，再保存受控媒体，最终以单个事务提交引用。失败清理 staging；成功输出不覆盖已有文件。任务历史可重读，旧进程未完成的任务明确标记中断。

FFmpeg/Python 均使用参数数组和明确的本地工具路径。长任务传播取消信号，媒体解析有输出与时间限制。模型不可用时报告依赖、权重或设备原因；只有实际推理结果能作为建议或参考输出。

## 验收原则

每个模块至少覆盖一个真实用户任务和一个拒绝/失败路径。跨模块测试覆盖旧库迁移、模板与引用约束、原片更改、撤销/重做、带故事的加密包迁移、备份恢复与可玩分支。桌面测试操作真实界面和桥接，只替换系统文件选择器；构建成功不能替代交互验收。
