# 能力完成度与后续验证

当前为 Electron 0.3 开发预览。按完整用户工作流与失败路径验收，不把入口存在、模型适配器或外部工具名称当作功能证明。测试记录见[验证记录](VALIDATION.md)。

## 已实现工作流

- schema v3 九类对象、旧库迁移、可扩展模板、实体属性、证据身份、未知置信度、空间几何、逐词／关键点／关键帧。
- 事件、关系、状态变化、类型化分支故事、预演、节点信息性质与结构诊断。
- 直接绘制、多轨时间线、源帧索引、循环与快捷键；组合筛选、视觉候选及 SQLite FTS5 分页发现，短词有子串回退。
- 镜头切分、波形、SRT／WebVTT 导入；源校验／重新定位、代理、备份恢复、有界 undo／redo 和任务历史。
- 片段／边缘／固定与跟随裁剪／图片帧／音频／批量参考；共用音画时间原点处理延迟音轨和容器起点。
- 本地 OCR、HOG、光流、深度／姿态／蒙版／转写适配器与模型设置；缺失依赖和未验证路径明确区分。
- 制作项目／镜头／连续性、证据整理提示词、五套制作模板、多 takes 和当前选用结果；设定集、镜头清单、参考、总览图与候选输出的本地资料包。
- 数据集质量检查、已知同源分组、来源／剧集／实体划分、可复现 train／validation／test、原始与导出重基准记录、报告与数据集卡。
- `.cbox` 0.3 全图交换，导入桌面 0.1／0.2／0.3；完整／裁剪配置、JSONL／SRT／COCO，以及故事 JSON／RenPy／Godot 叙事交换。

制作平台标签仅供人工交接，没有 Seedance、LibTV 或 TapNow API 集成；平台资料未核实部分见 [AIGC 工作流](AIGC_WORKFLOW.md)。开放制作标准的调研不意味着已经接入。[数据集准备](DATASET_PREPARATION.md)描述实际分组保证与边界。

## 仍需验证或扩展

- macOS／Windows 真机、独立安装、签名、公证、硬件加速和本地模型部署。
- faster-whisper 真实中英文语音推理与 Depth Anything 指定权重路径；说话人分离为独立模型能力。
- 长片／大库：现有 Map 查找和 FTS5 分页不改变全图快照、整图写校验、30 次快照历史和索引重建的内存成本。10,000 条合成测试不是百万数据或长片交互承诺。
- VFR／HDR／旋转／多音轨的完整源帧与音频样本映射；当前仍使用浏览器播放器和秒级锚点。
- 跨剪辑与遮挡的身份重识别、语义检索、长期连续性判断、深度闪烁和分割边缘质量。
- takes 的完整输入参考快照、参数回执、QC 版本史、设定变化依赖与过期提示。
- 完整多次变换谱系、增量集合、全媒体加密与独立格式审计；任务数据集只能合并已有且明确的来源关系。
- 分组不能发现未知重复或未关联身份；质量筛选不能证明训练标签正确、分布均衡或模型效果。
- 外部平台实际能力核对与适配、OTIO／OpenAssetIO／USD／OCIO／IMF 互操作，均需单独实现和验收。
- 分支图的全状态可达性求解，以及 RenPy 完整图形运行时验收。
