# 实施顺序与验收门槛

目标不是一次堆满所有识别模型，而是每一阶段都能完成一条可检验的用户任务。阶段没有虚构工期；通过下列门槛再扩展。

| 阶段 | 交付 | 验收门槛 |
| --- | --- | --- |
| P0 本轮 | 研究、架构、模板、加密描述格式实验 | 合成素材 roundtrip、错口令、篡改、缺件和越界拒绝；不宣称桌面完成 |
| P1 可用的手工闭环 | macOS壳、库、探测/代理、精确帧、范围/区域/声音标注、集合导出与回读 | 一个自制复杂短片从导入到迁移，断网可用；VFR、旋转、多音轨、撤销和崩溃恢复 |
| P2 半自动提效 | 镜头建议、转录、说话者建议、人物轨迹、关键帧分割 | 人工修正时间与全手工基线比较；报告漏检、误合并、边界误差与设备资源 |
| P3 拉片与复用 | 镜头对比、声画关系、观察/解释卡、语义检索、训练适配器 | 对照真实检索任务；有明确用途的训练导出与分组切分，不以标签数量验收 |
| P4 发行与互通 | 签名公证、更新、稳定CBox、Windows/Linux适配 | 独立机器安装、升级/回滚、格式迁移、双实现互通、第三方许可清单 |

## 第一条开发切片

导入一段本地MP4和一个WAV → 按真实PTS/样本范围做标注 → 数据库关闭重开 → 加入集合 → 精确物化并生成清单 → `.cbox + media` 迁移到另一个目录 → 验证并重新定位。先完成这条，再做自动人物识别和漂亮的大型图库。

P1工程建议 `apps/desktop`、`crates/domain`、`crates/media`、`crates/cbox`、`workers/`、`schemas/`。这些是规划目录，本轮不建空壳假装模块已经完成。

## 自动标注准入

每个适配器声明输入/输出schema、模型/权重摘要、代码与权重许可证、设备需求、下载大小、耗时与失败模式。默认只生成 suggested。候选模型在短、中、难三类自有/授权样本上评估，验证遮挡、换衣、多人叠音和配乐；不以模型论文的 benchmark 代替电影素材实测。

## 发布前检查

素材权利与来源记录、第三方二进制构建和许可、系统目录访问范围、恶意文件与导入配额、崩溃后状态一致性、无网络工作、macOS最低版本/芯片支持矩阵、可访问性、备份恢复。训练与声音生成属于下游用途，软件不能替用户推定所有影视素材都获授权。
