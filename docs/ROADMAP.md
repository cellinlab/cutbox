# 实施顺序与验收门槛

目标不是一次堆满所有识别模型，而是每一阶段都能完成一条可检验的用户任务。阶段没有虚构工期；通过下列门槛再扩展。

| 阶段 | 交付 | 验收门槛 |
| --- | --- | --- |
| P0 已完成 | 研究、架构、模板、加密描述格式实验 | 合成素材 roundtrip、错口令、篡改、缺件和越界拒绝；不宣称桌面完成 |
| P1 进行中：可用的手工闭环 | Electron macOS壳、角色/场景等资产手工管理与导入导出、库、探测/代理、精确帧、范围/区域/声音标注、集合导出与回读、边缘参考导出 | 一个自制复杂短片从导入到迁移，断网可用；VFR、旋转、多音轨、撤销和崩溃恢复 |
| P2 半自动提效 | 本地深度参考、pose/mask导出、镜头建议、转录、说话者建议、人物轨迹、关键帧分割 | 人工修正时间与全手工基线比较；报告漏检、误合并、边界误差与设备资源 |
| P3 拉片与复用 | 镜头对比、声画关系、观察/解释卡、语义检索、训练适配器 | 对照真实检索任务；有明确用途的训练导出与分组切分，不以标签数量验收 |
| P4 发行与互通 | 签名公证、更新、稳定CBox、Windows/Linux适配 | 独立机器安装、升级/回滚、格式迁移、双实现互通、第三方许可清单 |

## 已实现的第一条开发切片

本地导入视频/音频/图片 → SHA-256 与缩略图 → 创建角色/场景/道具/声音资产 → 秒级范围与归一化矩形标注 → 加入集合 → `.cbox + media` 复制导出 → 独立目录验证、托管导入并重映射 ID → 关闭重开读取数据库。

另可把视频选定区间导出为原片参考或边缘 MP4；有进度、取消、临时文件清理和简要来源 sidecar。素材/资产有列表展示、搜索、详情和编辑；基础拉片视图把观察与解释分置于两个字段。

已使用实际模块的 Worker 集成测试跑通合成视频迁移，包括导出后删除原片、换数据库导入、重新启动，以及无效包/错误口令回滚。此结果不等于 P1 的全部验收门槛已通过。

代码按当前规模组织为 `desktop/` 后端模块与 `src/` 界面模块，未创建空的 monorepo 层级。未来规模需要时再拆包。

## P1 尚未完成的门槛

- 源 PTS/样本锚点、VFR 精确逐帧、旋转/多音轨正确性、代理视频与波形。
- 画布交互框选、轨迹/多边形、镜头边界校正；当前区域仅数值输入，拉片仅基础笔记。
- 撤销、修订审计、备份与崩溃恢复、持久任务与并发资源调度。
- 丢失源文件重新关联：SHA 去重目前保留已有路径，重导入同内容不能自动恢复失效源引用。
- 大库分页与全文检索；当前完整快照和前端名称/标签过滤只适合原型规模。
- 包导出当前复制完整依赖源文件；不按标注范围自动物化裁切，不自动加入已导出的参考文件。
- macOS 真机播放、安装包、签名公证、FFmpeg 构建许可与独立机器启动尚未验证。

深度视频可以通过本地模型实现，但当前没有已安装或接入的模型适配器，界面明确提示不可用；姿态、蒙版、转录也不能视为已实现。P2 开始前需确定模型许可、权重获取、设备预算与时序一致性评估。

## 自动标注准入

每个适配器声明输入/输出schema、模型/权重摘要、代码与权重许可证、设备需求、下载大小、耗时与失败模式。默认只生成 suggested。候选模型在短、中、难三类自有/授权样本上评估，验证遮挡、换衣、多人叠音和配乐；不以模型论文的 benchmark 代替电影素材实测。

## 发布前检查

素材权利与来源记录、第三方二进制构建和许可、系统目录访问范围、恶意文件与导入配额、崩溃后状态一致性、无网络工作、macOS最低版本/芯片支持矩阵、可访问性、备份恢复。训练与声音生成属于下游用途，软件不能替用户推定所有影视素材都获授权。
