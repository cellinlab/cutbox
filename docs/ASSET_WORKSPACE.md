# 角色、场景、道具与声音资产工作区

状态：首轮已实现四类资产卡、名称/描述/标签编辑、封面与素材关联、搜索、删除、关联标注展示和素材包导入导出，使用 SQLite 持久化。下文为完整目标，批量加入集合、组合筛选、关键帧轨迹与修订已接入；自动跨镜重识别与全量图形化关系分析仍需扩展。这里的“资产卡”是可编辑的语义对象集合；原始影音Asset仍为只读来源，二者不能混用身份。

## 页面结构

导航增加“资产”，包含角色、场景、道具、声音四类；另有原始素材库、标注、拉片、集合、任务。支持卡片/列表切换、搜索、标签/来源/审核状态筛选、排序、多选、批量加入集合与导出。无预览时使用明确占位，不虚构角色图。

| 类型 | 列表信息 | 详情与交互 |
| --- | --- | --- |
| 角色 | 封面、名称/别名、出现次数、服装版本、声音关联、审核状态 | 概览、参考图库、所有出现时间线、服装/造型版本、动作片段、声音、关系、来源与修订 |
| 场景 | 场景封面、名称、室内外、时间/天气、片段数 | 多视角图库、空间/道具关系、光线版本、环境声、相关镜头、分析与参考输出 |
| 道具 | 物件图、类别、属性、出现次数 | 多角度、持有/使用关系、交互动作、mask与来源 |
| 声音 | 名称、类型、时长、波形、说话者/声源关联 | 试听、片段范围、转录、情绪/语气观察、环境污染、技术参数、使用依据 |

角色≠演员≠声音身份；支持独立对象间的关系。场景资产表达可复用地点/环境，一次剧情场景是带时间的实例；同一地点的白天/夜晚可以是版本，不自动合并为同一镜头或叙事场次。

## 新增与编辑

- 从列表“新增”：先选类型，输入名称，拖入图片/音视频参考，选择封面和属性。可以创建暂时没有来源的草稿，明确标记。
- 从影片“提取为资产”：选择已有轨迹/区域/声音区间，新建对象或关联已有对象；带入真实来源和范围，不复制一套孤立标签。
- 从详情编辑：改名/别名/标签、属性与备注，添加/移除参考，排序/替换封面、修正范围、编辑服装或场景状态版本；保存与撤销状态清晰。
- 参考图支持放大、画区域、比较；视频支持片段循环、逐帧回源；音频支持波形范围与试听。参考输出有原片/派生对比和“重新生成”，不会将假想的三维模型当实际资产。
- 合并/拆分角色前预览受影响轨迹、对白和集合引用；可撤销，不因同名或相似脸自动合并。删除默认软删除语义卡，不删除源媒体；有引用时显示影响并允许恢复。

## 与参考生成和集合联动

角色详情可选“本次出现/选定出现”生成pose、mask、主体裁切；场景详情可生成深度/轮廓参考。输出属于派生资产，带源anchor、transform、配方与版本。用户可将角色的封面+服装版本+动作+对白打为角色集合，或场景多视角+环境声+深度打为场景集合。

导出预览列出依赖、范围、修订、是否包含原片/派生文件、未审核字段、预计体积与缺失源；只导引用与携带文件两种模式明确区分。导入成功后出现在对应列表，可以编辑并再次导出，不局限于只读附件。

## 导入/导出合同

规划实体包profile为 `character`、`scene`、`prop`、`sound`、`mixed`，共用CBox外层。将扩展当前仅含assets/annotations的实验schema；原型验证器必须在支持新版前拒绝新版，不能静默丢弃entities/relations。

- 包含稳定entity UUID、实体修订、类型、本体版本、展示信息、成员anchor、关系、引用修订、来源与用途记录；原始/派生媒体与mask等依赖按哈希列清单。
- 导出默认封闭依赖：引用的媒体、子对象及必要关系端点齐全；不想携带的外部对象保留明确external reference，UI展示未解析，而非伪造空对象。
- 导入先验证schema/认证/哈希和配额，再展示新增、同一ID同修订、同一ID冲突、缺件、外部引用和不支持字段。默认冲突不覆盖：可保留为分支修订、显式合并或复制成新ID；复制时一致重写内部引用并保留来源映射。
- 内容相同的媒体按哈希去重；语义实体不因同名或共享图片自动去重。未知新版字段可保存为只读扩展或拒绝整个包，禁止无声丢失后再导出。
- 用户确认导入方案后，以staging+数据库事务提交；失败回滚。本轮未实现该事务、实体schema或页面，不能把现有`.cbox`往返测试当实体包兼容证据。
- 本地草稿与交换包都保留用途/许可声明；描述加密与媒体明文模式沿用现有明确提示。

## 验收用户剧本

手工新增角色→导入两张参考图→从影片绑定两段出现→分别标两种服装→挂接画外音→选封面与排序→导出角色包→在空库导入→编辑属性→再次导出。实体身份、时间范围、关系和哈希可追溯且字段不丢失。

场景执行同样往返；额外覆盖地点与场景实例不混淆、重复导入不重复建媒体、同名不同对象不自动合并、同UUID冲突不覆盖、缺件/路径越界/不支持版本拒绝、软删除恢复和取消导入。
