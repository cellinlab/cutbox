# 本地参考素材生成与导出

状态：Electron 预览版已实现选定秒级区间的 MP4 原片参考和灰度边缘视频，带任务进度、取消及来源 sidecar。下表描述完整目标；主体跟随裁切、关键帧/序列导出、阈值调节与模型配方仍待实现。尚未接入深度等模型或在 Mac 运行验证。

## 输出类型与实施次序

| 类型 | 输出与用途 | 实施条件 |
| --- | --- | --- |
| 原片参考 / 主体裁切 | 选定区间MP4、关键帧、对象跟随裁切 | P1，复用精确导出；跟随裁切需已审轨迹与平滑窗口 |
| 边缘 / 轮廓 | 灰度边缘视频、PNG序列；构图与轮廓条件 | P1低成本参考配方；先用确定性边缘算子，阈值可调 |
| 深度 | 灰度深度参考MP4、高精度深度序列、可选伪彩预览 | P2首个模型配方；分开标记逐帧估计与时序模型 |
| 人体姿态 | 骨架参考视频、关键点JSON，后续手/脸细节 | P2，模型选择与许可单独核验；支持关节纠正和轨迹绑定 |
| 人物 / 对象蒙版 | 二值mask视频/无损序列、分对象mask、合成预览 | P2，基于分割跟踪与人工修正；遮挡/丢失状态明确 |
| 语义分割 | 类别ID图、palette、标签映射与可视化视频 | 后续；不同下游的颜色和类别编码不通用 |
| 法线 / 光流 | 法线图、运动场及预览 | 实验候选，不作为首版承诺；必须注明估计来源与坐标约定 |

参考配方不得承诺适配所有生成模型。通用输出之外，目标适配器声明分辨率、帧率、时长、深度方向、pose schema、类别palette、文件格式与是否需要音轨；无已核验适配器时显示“通用参考”。本软件不自动上传给生成平台。

## 深度方案与证据

2026-10-15核验官方README，未运行模型：

- [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)：官方用例包含cuda/mps/cpu选择，文档链接Apple Core ML版本，提供视频运行脚本。Small模型声明Apache-2.0，Base/Large/Giant声明CC-BY-NC-4.0。优先评估Small作为Mac本地方案；Core ML转换产物的具体模型卡/许可仍需接入时核对。
- [Video Depth Anything](https://github.com/DepthAnything/Video-Depth-Anything)：时序视频深度，提供相对/metric模型、灰度视频、NPZ/EXR输出。官方Small性能表来自A100上的32帧518×518输入；不是消费级Mac承诺。README声明Small Apache-2.0、Base/Large CC-BY-NC-4.0，具体metric权重接入前单独确认。实验streaming模式文档明确存在质量下降。

逐帧模型与时序模型都可在本机作为离线worker运行，但Mac加速、算子支持、内存与速度必须用目标设备测试。完整下载并安装后应可断网执行。若仅支持CPU，展示低速预览/分辨率预算，不假装有GPU支持；不自动切换到云推理。

## 正确性约束

1. 默认输出是相对深度估计，不标米、不当真实几何或测量真值。metric模式只有明确模型与单位才启用，仍保留模型估计性质。
2. 按镜头处理：切镜头重置时序状态，重叠窗口拼接只在同镜头内做；不跨切点平滑。提供原片/深度同步、滑杆、边缘叠加与循环对比，观察抖动、遮挡与边界漂移。
3. 禁止逐帧独立min/max拉伸作为默认导出；它会导致亮度与相对尺度跳动。记录逐镜头固定映射/百分位范围、裁剪区间、inverse-depth或depth语义、近白远黑方向。固定归一化本身也不能消除模型漂移，不宣称等同时间一致性。
4. 播放用MP4只是一种可视化。精密下游同时提供16位PNG（含量化映射）或浮点EXR/NPZ及原始单位；不得用8位有损灰度视频冒充原始深度数值。
5. 原片与参考输出共用frame index→source PTS映射；目标固定fps时显式记录重采样、重复/丢弃帧，保留旋转、裁切与缩放变换。预览对比不能靠两个播放器的currentTime近似一致来验收。
6. 配方记录源哈希、源修订、模型/权重摘要、输入尺寸、设备与精度、软件版本、归一化和编码参数。结果作为派生Asset回库，不覆盖原片。
7. 默认条件视频不含音轨；可明确选择保留源音轨，导出预检提示是否包含人声。mask优先无损输出；透明主体输出须使用支持alpha的格式，普通MP4不承诺透明。

## 操作流程

素材/时间线/角色详情选择片段 → “生成参考” → 选深度/姿态/轮廓/mask配方 → 选主体、范围、分辨率、fps和目标格式 → 生成短区间预览 → 对比、调整 → 排队生成 → 单独导出或连同原片和标注加入集合。

默认先预览用户选定的短区间，不对整部影片启动昂贵任务。显示模型下载与存储预算，任务支持取消、失败重试和明确的中断状态。画面可调深度方向/范围、裁切、边缘阈值、pose显示与选中对象；手工改mask或关键点产生新修订，原模型输出保留。

## 验收

目标Mac上用授权样本验证：静止镜头、快速运镜、遮挡、透明/反射物、切镜头、VFR和竖屏。记录推理时间、峰值内存、输出帧数/PTS映射、边界漂移和人工观察到的闪烁；候选与验收通过分开标记。导出重读验证数据精度、palette、深度方向、模型版本和素材哈希；取消、磁盘满、离线重启不损坏原片。
