# 交互：从观看到可复用集合

## 一条主线，六个工作区

左侧包括素材库、资产、标注工作台、拉片、素材集合、标注模板、故事与关系、分析与维护、任务中心；保持当前素材、游标、选中对象和撤销历史。没有模型也能完成主线，AI 不是默认聊天框。

```text
┌ CutBox / 库名 ───────── 搜索 / 工作区 ───── 任务与存储 ┐
│ 素材/场景/对象 │         画面与覆盖层       │ 当前对象   │
│               │    查看/框选/点选/轨迹     │ 字段+证据  │
│ 筛选与审核状态 │       A/B 可选比较        │ 建议差异   │
├───────────────┴──────────────────────────┴───────────┤
│ 镜头 │ 角色轨迹 │ 服装 │ 对白 │ 声音 │ 分析（按需显示） │
│            可缩放时间线 + 波形 + 入出点                  │
├ 选中范围 / 回源时间 / 复用预览 ───────── 加入集合 ──────┤
└──────────────────────────────────────────────────────┘
```

Library 的默认任务是快速找到片段，不是看所有元数据。导入时选择“引用原片”或“复制到库”，马上反馈磁盘需求、代理状态和文件变化；不主动移动原始素材。模型分析按配方选择“只切镜头”“加对白”“人物/对象建议”，展示估算与可取消状态。

## 标注动作与作用域

1. 播放定位，I/O 选择范围；逐帧键通过精确帧通道更新 anchor，不能仅拖浏览器视频进度。
2. 点击画面对象或画区域，选中轨迹；无轨迹时创建一次出现。按住修饰键为多选批量赋值。
3. 右侧属性明确写“本帧 / 选定区间 / 整条轨迹 / 所有出现”。默认最小范围，扩大前可预览受影响对象数量。
4. 服装改变时切属性区间，人物身份保持；遮挡时可标 invisible/occluded，而不是用插值框冒充观测。
5. 接受 AI 建议看差异、来源模型、证据帧；可接受单字段/范围，不能一个按钮静默确认整片。
6. 人工覆盖与批量修改支持撤销；未保存、已保存、任务仍运行有不同状态。

快捷键是可改映射：Space 播放、J/K/L 变速、I/O 范围、左右逐帧、Enter 接受当前建议、Esc 取消。文本编辑焦点下不触发播放键。颜色外增加图标/文字，支持键盘导航、字幕字体缩放、深浅主题。

## 声画联动

点击转录词，跳到实际样本范围并显示附近视频；拖动词边界可试听前后上下文。重叠说话用多轨区间，不强制每时刻只有一个人。画外音直接标“未知/未映射声源”，不要求绑定屏幕人物。用户可把某声音轨迹与某角色建立可撤销关系，证据和置信范围可见。

人物面板提供“所有出现”胶片条、服装变化和关联声音；来源按角色/演员/说话者独立筛选。自动聚类仅建议，支持拆分和合并后回滚。

## Study：拉片不是标签换皮

镜头卡显示首中尾帧、长度、机位/运动/光色、对白与声音事件。用户选择分析维度后只展开对应轨道。两镜头同步或独立 A/B 比较，按角色动作/剪辑点定位；不是默认按绝对时间锁定不同影片。

观察区记录“画面发生什么”，解释区记录“为什么这样拍/产生什么效果”，证据链接到具体帧和声音。可以创建正反打、视线、动作匹配、节奏、声音桥等跨镜头关系；输出分析序列与镜头表。切镜头模型只建议剪辑点，不命名剧情场景或自动断言导演意图。

## Collections：决定要带走什么

集合成员是源引用+范围+对象+字段修订+导出配方。保存查询是动态视图；导出必须先冻结成员快照。用户可选择整段、区域裁切、帧序列、音频区间、附属标注与上下文边界。

导出表明确：目标用途、编码/采样、实际边界、预计体积、未审条目、授权状态、漏标与派生污染。提供“复用参考”“音频剪辑”“训练任务”不同配方，不宣称 `.cbox` 能直接喂给所有模型。

输出 `collection.cbox + media/`，最终回读确认缺件、哈希和版本；允许只导描述，但清楚标 external references，不能称可离线迁移。口令输入可切显示，有忘记口令无法恢复的说明。明确“本模式仅加密描述，素材文件可直接读取”；需要媒体保密时使用后续全包加密方案。

## 优先处理的失败路径

| 事件 | 用户看到什么 | 系统行为 |
| --- | --- | --- |
| 原片移动 | 缺源，已有缩略图仍可浏览 | 引导重定位并核对哈希，不自动认同同名文件 |
| 原片内容改变 | 新版本，与旧标注不匹配 | 保留旧身份，用户决定迁移 |
| AI 与人工冲突 | 建议差异 | 不覆盖 accepted 人工数据 |
| 模型不支持设备/OOM | 可手工继续，可降低配方 | 当前任务失败可重试，不关闭素材库 |
| 未审核/用途未明确 | 导出预检逐条解释 | 参考归档可保留unknown；特定训练配方要求满足其条件 |
| 口令错误/篡改/缺媒体 | 无法验证，显示原因类别 | 不导入部分数据库；不执行包中内容 |
| 导出中断/磁盘满 | 未完成导出 | 原始素材与集合快照保持，staging可清理/重试 |

## 验收用户剧本

给一个三镜头自制片段：角色A换外套，角色B在画外讲话，背景有音乐。用户应能区分角色/轨迹/服装状态，把B声源标画外而不误绑A，把中间一次硬切改正，挑出A穿蓝外套的所有已审区间，将两段音频与标注组集。重开项目/迁移目录后对象和范围不变；导出后改动一字节素材必须验证失败。这比“成功生成一千个标签”更接近产品成立。

## 资产与参考输出

Assets提供角色、场景、道具和声音的列表/详情及新增编辑、导入导出，见[资产工作区](ASSET_WORKSPACE.md)。从素材、时间线或资产详情选片段可打开“生成参考”抽屉，预览深度/边缘/pose/mask并导出，见[参考导出](REFERENCE_EXPORT.md)。
