# CutBox

CutBox 是一个本地优先的影视素材标注、拉片与素材集合制作工具。用户已确认名称 CutBox，以及 macOS 优先、架构兼容 Windows/Linux。设计基线：2026-10-15。

## 从目的推导

人真正需要的是：再次找到有用的瞬间，理解它为什么有用，把它连同来源和描述交给下一个创作或训练流程。文件夹不能表达人物跨镜头出现、衣服随时间变化、画外音与画面的关系；单一标签表也不能表达证据、推断和用途。

因此核心单位是「可以精确回到原素材的证据对象」，而非文件或 AI 对话。素材不因一次标注而被裁掉；同一对象可参与多个集合，集合导出时才物化。

价值函数：有效可复用素材数 × 检索成功率 × 标注可信度 ÷ 人工时间、计算与存储成本。“尽可能细”是模型可表达且按需可加深，不是导入时对所有帧运行所有模型。

## 用户与场景

- 影视创作者：按构图、调度、光线、剪辑、声音关系拉片，构建可回看的参考。
- 素材整理者：标人物、服装、姿态、物体、空间、对白、环境声；跨作品查找并组集。
- AI 创作者：导出有上下文和用途说明的参考片段、提示描述与音频素材。
- 数据集制作者：按明确任务定义标注本体、审核、切分与导出，保留来源与变换链。

## 最小成功条件

以自制或获授权的短片为验收材料。完成导入、校正镜头边界、人物轨迹与服装区间标注、对白片段修正、跨模态检索、加入集合、加密描述导出、换目录重新导入并定位来源。

覆盖至少：可变帧率、多人重叠讲话、画外音、遮挡后重现、人物换衣、竖屏旋转、不同音轨与采样率。不能因用户没有下载模型而无法手工完成闭环。

## 当前交付与状态

0.2 已实现从可扩展标注、事件关系到分支故事的完整数据模型。实体、模板、标注、集合、事件、关系与故事具有事务校验；旧库迁移、引用重映射、修订撤销、源重新定位、代理和备份恢复均有实现。

工作台提供画面框选／多边形、关键帧轨迹、多轨时间线、源帧时间索引和组合查询。媒体服务支持镜头切分、波形、参考片段、边缘、固定／跟随裁切、图像帧和音频输出。游戏化编辑器支持类型化变量、条件、原子状态变化、试玩和结构诊断；模拟不会回写原片观察。

本地 Python 适配器支持 OCR、HOG 人体检测、光流、MiDaS/Depth Anything 深度、MediaPipe 姿态／蒙版与 faster-whisper 转写。可用性取决于依赖与本地权重，不能由适配器代码推断所有模型已验收。实际执行结果见 [验证记录](../docs/VALIDATION.md)。

macOS 仍是第一发行目标，但当前验收在 Linux；真机 GPU、签名、公证和安装包另需验证。帧索引不等价于完整精确帧解码播放器；音频样本级剪辑、多说话人分离、自动跨镜身份重识别和深度时序一致性尚无交付保证。完整能力拆解见[实现契约](../docs/development/EXPANSION_CONTRACT.md)及[设计](../docs/development/EXPANSION_DESIGN.md)。

## 当前本地运行

需要 Node.js 24+、npm 和提供 libx264 的 FFmpeg/ffprobe；安装依赖后运行：

```sh
npm ci
npm start
```

`npm start` 构建后启动 Electron；单独 `npm run dev` 只启动网页，不具备桌面文件与数据库接口。`CUTBOX_DATA_DIR` 可指定独立测试库，`CUTBOX_FFMPEG`/`CUTBOX_FFPROBE` 可指定工具路径。

```sh
npm run build
npm test
python3 scripts/check_template.py --project
```

保留的 Python 3.12+ 格式实验可用 `.venv/bin/python -m unittest discover -s tests -v` 验证，其 schema 与桌面包不同。两种包都只加密 JSON 描述，素材文件保持明文；移动包必须携带 `media` 目录。当前格式仍属实验，不要作为唯一一份数据。

## 非目标与维护

首版不替代 NLE，不做音视频生成或模型训练，不上传源片，不承诺全自动理解所有人物和镜头含义。暂不做多人同步、云资产库、移动端和插件市场。

无需服务部署。macOS 签名、公证、安装包、GPU 推理和跨平台验收属于后续实现；没有下载地址或发行承诺。

## 已确认的功能扩展

本地参考视频生成：深度、边缘、姿态、分割蒙版等，支持预览、参数调整、独立导出与集合打包，详见[参考导出](../docs/REFERENCE_EXPORT.md)。角色、场景、道具、声音支持独立列表/详情、交互新增编辑、导入导出与来源展示，详见[资产工作区](../docs/ASSET_WORKSPACE.md)。资产、参考工坊与本地模型适配器已实现，具体运行依赖与验收边界见模型说明和验证记录。
